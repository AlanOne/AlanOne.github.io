Take 5 v0.19.0 · cheat sheet

Record / Edit / Mix / Master

Take 5 is an open-source music studio (a DAW) for Mac and Windows, made for bands and songwriters: record a whole band or yourself take by take, comp the best takes, edit audio and MIDI, write with built-in instruments, drum kits and a session drummer, mix with built-in effects, guitar amps and NAM captures of real gear, and master to streaming loudness against a reference track. Its layouts and key sets can work the way you're used to, and an assistant makes changes when you ask in plain words.

This sheet has the keys and steps to take a song from the first idea to a finished file. Keys are Take 5's default set. Single-letter keys work whenever you're not typing in a box, and almost everything can be undone with CtrlZCmdZ.

Before you start

Set up the sound once, learn a dozen keys, and know where everything is on screen.

Set up your audio interface

  1. Plug in the interface (and install its driver) before opening Take 5.
  2. Settings > Audio Settings… Ctrl,Cmd,: pick the driver type (ASIO on Windows), then the interface for input and output.
  3. Tick the inputs you'll record from and the outputs you'll listen on. Press Test to hear a tone.
  4. Buffer size: 128 samples for recording, 512–1024 for mixing a big song. Hear crackles? Go up one step.

Find any command

  • CtrlShiftPShiftCmdP Command Palette: type part of a name and press Return. Typos are forgiven; with no command, it finds the guide's tasks.
  • Ctrl/Cmd/ Shortcuts panel: every key and mouse gesture, beside the tracks.
  • Help > Tutorial: a guided tour on the open song.
  • Take 5 says when an update is available as it opens: Install Now gets it (on Windows it installs and opens again). Help > Check for Updates… (the Take 5 menu on the Mac) asks any time. About Take 5 says which version you have.
  • Hover any button for a tooltip; the status line at the bottom gives hints.
  • Used to other keys? Settings > Key Commands…: pick the key set you know (Set B to Set F), or change any key. A toolbar, status and info lines and a console-style mixer? View > Top Bars > Console Layout. Rather your own? View > Customize Top Bars…: drag the blocks at the top between rows, hide the ones you don't need.
  • A song from another computer, or a moved folder? Take 5 lists any files it can't find; File > Find Missing Files… finds them in a folder by name.

Get around the song

  • Click anywhere in the lanes (a clip, a section, a chord…) to move the playhead there, on the grid; the ruler puts it exactly where you click.
  • ← → a bar, Shift← Shift→ a grid step, Page Up Page Down a screen, Alt,Option, Alt.Option. a section, End the song's end. The view follows it.
  • Pinch or CtrlCmd-scroll to zoom (around the pointer, or the playhead when it's near); drag up or down in the ruler to zoom, double-click it to fit the song.
  • Two fingers scroll both ways; Shift-scroll goes along the song; middle-drag pans; AltOption-scroll makes tracks (or piano roll rows) taller or shorter.
  • While playing, the tracks follow the playhead (CtrlShiftFShiftCmdF turns it off); an edit or a scroll pauses it until the next Play.

Recording

Takes are saved in the song's Audio folder, and the song saves itself after every take.

Record a guitar or a vocal

  1. Add an audio track: + Track or CtrlAltNOptionCmdN.
  2. Pick its input in the track header's input menu.
  3. Click the track's R to arm it. Play: the meter should move without hitting the top.
  4. Press K for the click and choose a Count-in (1 bar is a good start).
  5. Press R to record, Space to stop.
  6. Recorded over an old take? It's kept as a take, not lost.

Hear yourself while recording

Click the headphones button in the track header to cycle:

  • Auto: you hear the input while the track is armed.
  • On: always. Off: never (use when your interface's direct monitoring is on).

You hear the input through the track's plugins, so you can play through the Amp. Hear a delay? Lower the buffer, or turn on Transport > Low-Latency Mode.

Record a whole band at once

  1. Tick every input in Audio Settings.
  2. Track > Other New Tracks > New Tracks for Unused Inputs makes a track for each.
  3. Arm them: Shift-click an R arms the selected tracks; CtrlCmd-click an R arms every track.
  4. Press R: each input records onto its own track.

Headphone mixes per player: Track > New Cue Mix…. Talk to them with Y (the mic is set in Transport > Talkback Settings…; it's turned down while recording).

A stereo source (amp modeller, keys, overheads) on one track: its input menu > Make Input 1 + Input 2 One Stereo Input.

Fix one part (punch in)

  1. Drag in the ruler over the bars to fix.
  2. Turn on the punch button (it goes red).
  3. Arm the track, start before the bars, press R. Only the punched part is replaced.

Transport > Pre-roll for Punch-in plays 1 or 2 bars first so you can play yourself in.

Lyrics for the singer

  1. View > Lanes > Lyrics Lane, right-click it > Paste Lyrics from Here..., then drag each line to where it's sung.
  2. Click a line to select it, CtrlCCmdC and CtrlVCmdV to copy it to the playhead (a chorus's lines, say). Double-click the lane for every line and where it's sung, to type new words and positions.
  3. Record: the Lyrics window opens by itself, the line big, the next under it (View > Lanes > Lyrics Prompter any time).

Loop-record takes, then comp the best

  1. Drag in the ruler to set the range, press C to loop.
  2. Arm and press R. Every pass becomes a take. Stop when you have enough.
  3. Click the track's Takes button to show the take lanes.
  4. Drag across the best part of each take: it goes into the comp. Click a lane to use a whole take.
  5. Right-click the track > Flatten Comp to make it one clip.

Guitar and bass tone

  • Record the DI and play through + > Built-in > Amp: change the tone later without playing again.
  • A real amp or pedal: Built-in > Capture Player, Load Capture... (the NAM captures on this computer, with a search box; Other File... for a .nam anywhere, copied into the song) or TONE3000 to pick one from tone3000.com.
  • Pedals before it: Overdrive (tightens high gain), Fuzz, Octaver, Pitch Shifter.
  • Through your real amp later: right-click the DI track > Reamp..., Measure, Set Up Reamp, record: it lines up to the sample.

Sing in tune while you record: Live Tune on the armed vocal track.

Click, count-in and tuning

  • K click on/off; the slider beside it is the click volume.
  • Transport > Click Sound: woodblock, cowbell, hi-hat, beep…
  • Transport > Click Only When Recording.
  • Transport > Click Output: send the click only to the drummer's headphones.
  • AltTOptionT Tuner: guitar, bass or chromatic, many tunings.

The click is never in an export.

Editing

Tighten, tune and clean up what was recorded. Every edit is one undo step, and the recordings themselves are never changed.

Tighten a multi-mic drum take

  1. Select the drum tracks (or their folder), CtrlShiftGShiftCmdG Group for Editing: a clip on one mic now selects the whole kit (cuts, moves, fades and comps go to every mic).
  2. Drag a marquee over a section (or select a clip), press Q: Quantise Group finds the hits on the kick and snare and cuts every mic at the same times, so the overheads and rooms stay in phase.
  3. Tab / ShiftTab jump the playhead from hit to hit to check it.
  4. Drums that follow the tempo or are warped: right-click > Stretch Mode > Percussive keeps the hits sharpest.

Tighten doubled guitars or vocals

  1. Select all the takes, right-click the tightest > Align Selected to This Clip > Tight or Natural: their hits move onto its hits.
  2. A double vocal: right-click the lead > Match Pitch of Selected to This Clip.

Tune a vocal

  1. Double-click the vocal clip: the Pitch editor opens under the tracks. Tick Correct.
  2. Drag a note to move it (AltOption-drag: in cents); drag its start or end to move its timing.
  3. Right-click a note: split, join, vibrato, drift, tilt, formants, level.
  4. More: screams left alone, breaths down, levelling, follow the chord lane, a harmony voice.

Move, copy or stretch a range

  1. T > Marquee Tool, drag across the bars and tracks.
  2. Drag inside it to move what's there (clips cut at its edges, automation too); AltOption-drag copies.
  3. Drag its right edge to stretch it: audio keeps its pitch, MIDI notes spread out.
  4. ShiftBackspace deletes it and closes the gap; Edit > Insert Silence opens one.

Find the exact spot

  • Drag the playhead in the ruler (or AltOption-drag anywhere in it) to scrub: the audio plays as it moves.
  • Tab / ShiftTab: the next or previous hit in the selected clip.
  • Right-click a clip > Spot...: type where it starts (17.3, 1:23.5).
  • Alt←Option← Alt→Option→ nudge it a grid step.

Fix a noise in a recording

  1. Right-click the clip > Repair: Remove Mouth Clicks, Remove Hum (50 or 60 Hz).
  2. Repair > Spectral Repair...: drag a box over a squeak or click in the spectrogram, Remove Selected.

Reuse a part

  • CtrlRCmdR Repeat: a copy right after it.
  • CtrlAltROptionCmdR Repeat Linked: copies that change together (notes, or an audio clip's fades, gain and effects). Right-click > Unlink to vary one.
  • Right-click a section marker: loop, duplicate or delete the whole section.

A band take played without a click

  1. Transport > Conduct Tempo, play the take and tap ShiftT on every beat.
  2. Stop, Make the Tempo: the bar lines fall on the played downbeats, the audio stays put.
  3. The click and MIDI parts now follow the band.

Writing & arranging

Sketch the song before (or after) the band plays it: instruments, a drummer, chords, lyrics, and the order of the sections.

Add an instrument

  1. CtrlAltSOptionCmdS New Instrument Track: a built-in Synth, Drum Machine, Keys, Bass, Guitar, Strings or Sampler, or your plugins.
  2. Double-click in its lane for a clip, double-click the clip for the piano roll; double-click to add notes.
  3. No keyboard? CtrlKCmdK plays notes from the computer keys. Played something good without recording? ShiftR keeps it.

A drum part in a minute

  1. Add section markers (Alt'Option') and name them: intro, verse, chorus.
  2. Track > New Drummer Track, press Play.
  3. Track > Drummer...: a style (Rock, Punk, Metal...), how busy and loud each section is, its fills, and the kick following the bass.
  4. Turn into MIDI to edit every hit in the drum editor.

Chords and ideas

  • View > Lanes > Chord Lane, double-click to add a chord (Am7, F#dim).
  • Right-click the lane > Chords > Chord Ideas or Melody Idea, then Make a Clip from the Chords to hear them.
  • Hum the tune into a mic, right-click the clip > Melody to MIDI: the notes on a new instrument track.

Write parts faster

In the piano roll, MIDI > Transform Notes on the selected notes:

  • Strum Chords down, up or alternating, like a guitar.
  • Add Flams, Grace Notes, Ratchets, Chop into Repeats.
  • Chance: a hi-hat note that plays some of the time; Euclidean Rhythm... for a pattern.

Try the song in another order

  1. Track > Arranger Chains: click the sections in the order to try (a chorus twice, no bridge).
  2. Play Chain to hear it; make more chains to compare.
  3. Flatten into Song... when one wins: every track rewritten in that order, one undo.

Words and parts on paper

  • View > Lanes > Lyrics Lane: paste the words, drag each line to where it's sung.
  • Right-click a MIDI track > Notation: sheet music, or tab for a guitar or bass part.
  • File > Export Other Formats > Sheet Music... prints it or saves a PDF or MusicXML.

Mixing

Press X for the mixer (or click its ×, top right, to close it). View > Windows > Mixer Below Tracks or Mixer in Own Window to place it.

Balance first

  1. Set every level with the faders before adding any plugin.
  2. Then pan: guitars left and right, kick, snare, bass and vocal in the middle.
  3. Keep the master meter out of the red; turn tracks down, not the master up.

Solo and mute

  • M mutes, S solos (a soloed track keeps its reverb).
  • AltOption-click S: solo only this track.
  • Shift-click S: dry solo, without its reverb and delay (shows D).
  • Right-click S > Solo-Safe: a reverb bus that stays on.
  • Mix > Unsolo All / Unmute All.

Clean up and shape each track

Select a track, Mix > Add Channel Strip: a Gate, EQ and Compressor before the fader.

  • Gate: raise Threshold to silence noise between notes.
  • EQ: cut what's muddy or harsh before boosting anything.
  • Compressor: Threshold and Ratio even out the level, Makeup brings it back up.

Reverb and delay on a bus

  1. Track > Other New Tracks > New Bus, then add Reverb, Convolution Reverb or Delay on it: on a bus they start fully wet.
  2. On each track: right-click > Send To > the bus (or + Send on the strip).
  3. Turn each send's knob for how much of that track goes in.
  4. A throw on one word: cut it into its own clip, right-click > Clip Effects > Add an Effect...; it moves with the clip. Render Into the Clip bakes it in (and can be taken back).

A big session

  1. The button under the track headers > Show Only > Drums (or Vocals, a folder, a set of your own): only those tracks, in the tracks and the mixer.
  2. Select tracks and move one's fader: the others follow (pans, mutes and sends too).
  3. Mix > Save Mix Snapshot... to compare versions of the mix; Mix > Mix Snapshots recalls one.
  4. Crackles? Click the CPU reading at the bottom right: the busiest track and plugin are at the top.

Group tracks

  • CtrlShiftDShiftCmdD Group into Folder: a folder is a bus, so one fader and plugins for all the drums.
  • Track > Group > Group into VCA: one fader moves all their faders together.

Automate (moves during the song)

  1. Click the track's A to show its Volume, Pan and send lanes; pick any plugin knob from the lane's menu.
  2. Click in a lane to add a point, drag to shape, AltOption-click a point to delete it.
  3. Or set the mode to Touch or Latch and ride the fader while it plays.
  4. Right-click a lane > Draw Shape: fade, swell, duck over a selected range.
  5. A goes to the next track that has automation, its lanes open (ShiftA back): to find what's automated.
  6. Touch a knob or fader: its track's lane shows it; AltAOptionA opens the lane for the last one touched.

An analog desk's sound

Mix > Console Mode: a Console on every channel and the mix, rounding off peaks with a little warmth. Its Drive sets how much; the same command takes them off.

Stems from another studio? Track > Colour Tracks by Instrument colours them and gives each an icon.

Duck the bass under the kick

Put a Compressor on the bass, right-click its slot > Sidechain From > the kick track.

Heavy guitars and bass: parts of the sound on their own

  • + > Built-in > Split: paths side by side in one slot, each with its own plugins. Split by Frequency to distort a bass's top and keep its lows clean; Nothing for parallel paths; Mid and side to widen only the sides.
  • Multiband Compressor: tighten the boom of palm mutes without touching the top. Dynamic EQ: a cut that only happens on the loud chugs or harsh hits.
  • Parallel compression without a bus: the Compressor's Mix knob.

Fewer knobs, less CPU

  • B Smart Controls: a few big knobs (Drive, Tone, Squash, Space) that each move several settings.
  • Right-click any knob > Modulate With: an LFO in time with the song, or an envelope follower on another track to duck it (View > Panels > Modulators).
  • CtrlBControlB Bounce in Place: the track becomes audio, effects and all.
  • Right-click a track > Freeze to free CPU and keep it playing.

Mastering & export

Make the finished mix loud enough, check it against a song you like, and export it.

Build a mastering chain

  1. On the master strip, click + > Built-in and add, in order: EQ, Compressor, Limiter.
  2. EQ: small, broad moves (1–2 dB).
  3. Compressor: gentle, a low ratio, 1–3 dB of gain reduction.
  4. Limiter last: raise its gain while watching LUFS INT and TRUE PEAK on the loudness meter. Keep the true peak under −1 dB.

Compare with a reference song

  1. Mix > Choose Reference Track…: pick a finished song you like.
  2. AltROptionR (or Mix / Ref) switches between your mix and it, at the same place in the song.
  3. Leave Match Reference Loudness on so louder doesn't fool you. After changes: Measure Mix Loudness Again.

Check the master

  • AltMOptionM Master Off: the mix without the master's plugins, at the same loudness. Does the master actually help?
  • Mix > Mono: does the bass or vocal disappear?
  • Mix > Dim: does it still work quietly?
  • Mix > Analyser: the spectrum, a spectrogram, a vectorscope (is it wide? out of phase?) or the level over the last minute, with the stereo correlation.
  • Mix > Listen Bus…: room or headphone correction on what you hear only, never in the export (Listen on the master strip).

Or let the assistant master it

  1. CtrlAltAOptionCmdA opens the Assistant (needs Claude Code installed and signed in).
  2. Ask: “master this for streaming, punchy” or “master it like the reference, −14 LUFS”.
  3. It measures, sets the EQ, compressor and Limiter, and checks again. One CtrlZCmdZ undoes it all.

Export the song

  1. CtrlECmdE File > Export…
  2. Tick formats: WAV, AIFF, FLAC, MP3 (one file each). 24-bit for masters, 16-bit for CDs.
  3. Whole song (with the reverb's tail after the last clip), or Loop range for part of it.
  4. Loudness: As mixed, or a target from the table below.
  5. Fill in Title, Artist, Album, Year for an MP3. When it's done it shows the loudness and true peak.

An album or EP

  1. File > Album..., Add Songs... in order, a gap or crossfade after each.
  2. Match to -14 LUFS, Render Album...: a WAV per song as loud as the others, one long WAV with track marks, and a cue sheet.

Other exports

  • Stems: one file per track, folder and bus, for another studio. They add up to the mix before the master's plugins.
  • Each section: one file per section marker (add markers with Alt'Option').
  • File > Export Other Formats > Export Range as WAV…: each track in a marquee range.
  • File > Export Other Formats > Export AAF… for other music apps and video editors.
  • File > Export Other Formats > Export DAWproject... for other music apps (the open format): MIDI, sends, automation, VST3 settings.
  • File > Share with Bandmates to send the song itself.

Before you export
  • Nothing soloed or muted by mistake: the export plays what you hear.
  • The click, the reference, Mono, Dim, Master Off and the listen bus are left out by themselves.
  • Saved with CtrlSCmdS. Want a safe point? File > Save Snapshot…
If something goes wrong

No sound: Audio Settings > Test; check Dim is off and nothing is soloed (Mix > Unsolo All).

Crackles: raise the buffer size; freeze heavy tracks; on Windows use ASIO.

MIDI keyboard silent: play an armed instrument track; check it's ticked in MIDI > MIDI Inputs.

Stuck notes: Transport > Panic, or double-click the play button.

Space or R does nothing: you're typing in a box. Click an empty part of the tracks.

Lost work: File > Song History… lists earlier saves to listen to and restore. Take 5 also keeps a recovery copy every 2 minutes.
