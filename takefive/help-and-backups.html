The assistant

Set up the assistant

The assistant makes changes you ask for in plain words, through Claude Code on your own Claude plan, free through Google's Gemini, or free and offline through a model running on your own computer. With Claude Code:

  1. Install Claude Code from claude.com/code.
  2. Open Terminal (on Windows, Command Prompt), type claude, and sign in once.
  3. In Take 5, Window > Panels > Assistant, CtrlAltAOptionCmdA. Take 5 looks for Claude Code when it opens: if you installed it while Take 5 was open, press Look Again in the panel (shown while there's nothing to run on), or ... > Look for Claude Code Again, or reopen Take 5.

With Gemini (no Claude plan needed):

  1. Edit > Preferences... > General > Assistant..., set Use to Gemini (the window shows what each choice needs: Gemini's key and model), then Get a Free Key...: sign in to Google AI Studio with a Google account and create a key (no card needed).
  2. Paste it into Gemini key and press Save. Or set Use back to Automatic, which uses Claude Code when it's installed, else Gemini when there's a key. With Use on Claude Code it never falls back to Gemini.
  3. Open the assistant: Window > Panels > Assistant.

Gemini model is the model it asks (gemini-flash-latest, the newest Flash, unless you change it; left empty, it's that); Choose Model... (with the key typed in) lists the models your key can use, the newest Flash and Flash-Lite first, to pick one. After Save, the status line says what the assistant runs on; saved while it's working on a request, it changes over once that's done. Gemini's free tier has limits per minute and per day, each model its own: when the model's limit is reached it asks the lighter Flash-Lite model instead (and says so in the chat), and when Flash-Lite's is reached too it says so, or waits a moment when the wait is short. When Google's servers are busy ("high demand") it asks again a couple of times, then asks Flash-Lite; with no answer within a minute it switches to Flash-Lite at once. Once Flash-Lite has answered for it, the next 10 requests that get an answer go straight to Flash-Lite, then it tries your model again. If Flash-Lite is busy too, or doesn't answer within a minute either, it says to try again in a few minutes. Google may use what's sent on the free tier to improve its products. The key is kept in Take 5's settings on this computer (not encrypted) and never written to the log. With a model on this computer (free, offline, private; see "Run the assistant on my own computer"), Local Models... installs one with a click; one in Ollama or LM Studio is Use > Local model (Ollama, LM Studio). The panel's ... menu shows what it runs on, and has Assistant Settings.... The assistant needs a song open.

Run the assistant on my own computer

The assistant can run on a model on your own computer: free, offline once the model's downloaded, and nothing leaves the computer. Take 5 runs the model itself; nothing else needs installing:

  1. Edit > Preferences... > General > Assistant..., Use: Built-in model, then Local Models... lists the models it can run, each with its download size, the memory it needs and a line on what it's like. The one that suits this computer's memory says Suggested for this computer (Qwen3 8B on a computer with 16 GB or more; a smaller one with less). A model that needs more memory than the computer has says so: it's slow, or may not load.
  2. Click one and Install (or double-click it). A window shows each step as it goes: the download (how much, how fast, the time left), the check, the model loading, and a first question to try it. Stop stops it, and a part downloaded is deleted.
  3. When it's done, the assistant uses the model at once (Use reads Built-in model), and the status line says so. Open the assistant (Window > Panels > Assistant) and ask.

The model loads when a song opens with the assistant on it (a few seconds, longer for a big one), and uses its memory while Take 5 is open; it's let go when the assistant is switched to something else. In Local Models..., Use switches to another model that's installed, and Remove deletes one (its download is several GB). The models are kept in the Models folder in Take 5's settings folder (Language). A Mac with Apple silicon runs them on its graphics chip. A Windows PC runs them on its graphics card when the card's driver has Vulkan (any recent NVIDIA, AMD or Intel driver does); the parts of a big model that don't fit the card's memory run on the processor. A PC without one runs them on the processor, which is much slower: there, once a model loads, it spends a few minutes reading the assistant's instructions (a request sent meanwhile waits for that), and then answers in a minute or so; a smaller model is quicker.

Run the assistant on a model in Ollama or LM Studio

If you already use Ollama or LM Studio, the assistant can use the models there instead. It needs a model that can use tools:

  1. Install Ollama (ollama.com) and download a model that uses tools, in Terminal (Command Prompt on Windows): ollama pull qwen2.5:7b (about 5 GB; a bigger one, 14b or 32b, does better if the computer has the memory for it). Or install LM Studio (lmstudio.ai), download a model there and start its server (the Developer tab).
  2. In Take 5, Edit > Preferences... > General > Assistant...: Use Local model (Ollama, LM Studio); Local server is Ollama's address, http://localhost:11434 (for LM Studio, http://localhost:1234). Choose Model... lists the models it has: pick one. Save.

It does what it does through Claude Code or Gemini (changes as one undo step, answers from the guide, the app's commands), as well as the model can: a small model on a laptop is slower and gets more wrong than Claude or Gemini, so start with simple requests. The first request after starting can take a while as the model loads (it waits up to five minutes). If nothing answers, it says so: start Ollama (or LM Studio's server) and ask again.

Ask the assistant to change the song

Type a request in the assistant panel and press Return: "compress the bass a bit", "make the chorus 2 dB louder", "add a bar of silence before the outro", "pan the rhythm guitars wider", "transpose the arp up an octave", "set the tempo to 120". It says what it changed. Each request is one undo step: CtrlZCmdZ takes the whole request back (Edit > Undo names it "Assistant: ..."). A menu command it runs is an undo step of its own, and settings it changes (the audio device, the theme, the click) aren't undone. While it works, the box shows what it's doing and for how long, and Send becomes Stop: it stops after the step it's on, keeping what it changed so far (one undo step). A reply too long for the panel opens at its start. With Gemini, a request that takes more than 25 steps stops: ask for less at once.

Ask the assistant about the song or about Take 5

Ask questions too: "why does the mix sound muddy?" makes it analyse the mix before answering, without changing anything. It can also answer "how do I..." questions from this guide, find menu commands and their shortcuts, run commands (show the mixer, start the tuner, turn on the loop), and read and change settings. It asks before changing anything that could cut the sound, such as the audio device or buffer size, and changes it only once you've said yes. Besides those, it can switch MIDI inputs and outputs, the click's sound and output, the count-in and pre-roll, and the theme. It knows every plugin you have, built in and installed: it can add one by name, turn any of its knobs ("set the reverb's mix to 30%"), load or save its presets, and put another instrument on a track ("give the keys a grand piano sound"). It won't open, close or save songs, quit, or undo for you. Click one of its messages and press CtrlCCmdC to copy it (as plain text); CtrlACmdA copies the whole conversation; right-click for Copy and Copy Conversation.

What the assistant can and can't do

It works only on the open song and Take 5's own commands and settings: it can't open files you choose, run other programs or touch anything outside the app (it writes only into the song's folder: a DAWproject export, a TONE3000 tone it downloads). Only the song's details (track names, levels, plugins, notes, lyrics, measurements), the guide's text and your audio devices' names go to Claude (or Gemini), never audio. It remembers the conversation until you choose ... > Clear Conversation, open another song, save the assistant's settings, or quit (with Gemini, a request that failed or was stopped isn't part of what it remembers, though what it changed stays in the song). If Claude Code isn't installed, isn't signed in, Gemini's key is wrong or its limit is reached, or the internet is off, the panel says so: a request that fails before it starts leaves the song alone; one that stops partway keeps what it changed (one undo step). On Windows, a request to Claude Code can be about 32,000 characters at most.

Backups, history and recovery

Undo several steps at once

Edit > Undo, CtrlZCmdZ, and Redo, CtrlShiftZShiftCmdZ; the menu names the step. Edit > History lists the last 25 steps: choose one to go back to before it in one go. Fader, pan, send and plugin-knob moves are undoable too (one step per drag), and each assistant request is a single step. Saving isn't a step: after a save, Undo still undoes your last edit. Insert Silence, Delete Time and deleting a range are one step each. The history goes when the song closes (and after Remove Unused Media..., Restore or Recover). While the assistant is working, stop it first. For versions from earlier saves, see "Go back to an earlier save".

How autosave and backups work

While there are unsaved changes, Take 5 saves a recovery copy every 2 minutes (not while recording): a hidden file beside the song, gone when you save or close without saving. Each File > Save (CtrlSCmdS) keeps the previous save in the song's Backups folder, "<song> <date> <time>" (at most one every 5 minutes, the newest 20). The song is also saved when a recording stops.

Recover after a crash

If Take 5 stopped without saving (a crash, a power cut, a force quit), the next time you open the song it offers the recovery copy: Recover Changes brings your unsaved work back; Open Last Save opens the song as last saved and drops the recovery copy. Recovering puts the recovered song in place of the song file at once, and the last save goes to the Backups folder: to go back to it, use File > Revert (closing without saving doesn't). A recovered song counts as unsaved until you save it, so closing it asks whether to save; the recovery isn't offered again.

Send a crash report, or turn them off

If Take 5 closed unexpectedly or stopped responding (and was ended), the next time it opens it asks whether to send a report so it can be fixed. The report says where Take 5 stopped, what it was doing just before, which version it is and what kind of computer: your user name, the names of your songs, tracks and files, and anything you said to the assistant are taken out. Show Report opens exactly what would be sent; the box above the buttons is for what you were doing, if you'd like to say. Send sends it (without an internet connection, at the next launch), Don't Send doesn't, and neither asks about that crash again. Tick Always send without asking to skip the question from then on; Help > Send Crash Reports Without Asking (also in Edit > Preferences... > General) turns that on and off. Nothing is sent without your yes.

Go back to an earlier save

  • File > Revert lists earlier saves (not snapshots) by time, newest first; pick one and Revert (unsaved changes are lost; the current save is kept as a backup).
  • File > Project History... lists backups (SAVED) and snapshots (SNAPSHOT), newest first. Select one and press Listen (or double-click it) to hear 30 seconds of that version from the playhead (or the loop) without changing the song (Stop ends it). Restore... makes it the song again; the song as last saved is kept as a backup. The undo history goes with a restore.

Bring back a deleted track

File > Project History..., pick a save from before you deleted it, then Bring Back Track: tracks you've deleted since are listed under "Deleted since then". It comes back where it was (in its folder, if that's still there), with its clips and plugins. As It Was Then (a Copy) brings back a copy of how a track used to be, "<track> (earlier)", after it. CtrlZCmdZ takes it away again. If its audio has been cleaned up since, it says how many clips lost theirs.

Save a named snapshot

File > Save Snapshot... (or Save Snapshot in Song History) keeps the song as it is now under a name ("before the rewrite"), unsaved changes included (the song file itself isn't saved). It's a file in the song's Snapshots folder (a name already used gets a number). Snapshots show marked SNAPSHOT in File > Song History... and are kept until you delete them from that folder.

Keep a second copy on another disk or in the cloud

Edit > Preferences... > General > Second Copy of Backups... (or Second Copy... in Song History, where it shows where the copy goes): choose a folder on another disk or one a cloud service syncs, outside the song's folder. It's one folder for every song. After each save (and each snapshot), a folder named after the song's folder there gets everything in it (song file, backups, snapshots, audio, exports), in the background, copying only what's changed. Backups dropped from the song are dropped from the copy; deleted audio and snapshots stay there. With a folder chosen, the same command offers Choose Another Folder..., Turn Off and Show in Finder (Show in Explorer on Windows). If the disk isn't connected, the status line says the copy wasn't made.

Start songs from a template

Set up a song the way you like to start (band tracks, inputs, buses, tempo, click), then File > Save as Template... and name it (a name you've used replaces that template): tracks, plugins, buses and settings, no clips, takes or sections, nor its comments or what ties it to a shared song. File > New Project from Template starts from it, and Edit > Preferences... > General > Template for New Songs makes File > New Project... always use it (None (one audio track) goes back: one audio track, 120 BPM, 4/4). A new song from a template starts with the playhead at the start, wherever it was when the template was saved. Templates are kept with Take 5 (its Templates folder), for every song.

Tidy up a song folder

  • Media > Collect Audio into Project copies the audio its clips use from elsewhere into its Audio folder, so the folder works on its own (one undo step; it says how many files, and any missing).
  • Media > Remove Unused Media... lists files in the Audio folder that nothing uses (not the song's clips, takes or alternatives, nor its backups and snapshots) and, on Move to Trash, moves them to the Trash (Recycle Bin on Windows). It clears the undo history.

Find files a song is missing

When a song opens and some of its files aren't where it says (it came from another computer, or a folder was moved or renamed), a message lists them: its clips' audio, the Capture Player's captures and cabinet IRs, the reference track. The rest of the song plays. Find in Folder... looks through a folder you choose, and the folders in it, for each by its file name and points the song at what it finds (one undo step); Later leaves them, and the message comes back the next time the song opens. Media > Find Missing Files... does it any time.

Troubleshooting

I can't hear anything

  1. Check Edit > Audio Settings...: the right output device, its output channels ticked, and press Test for a tone.
  2. Check the master fader and that Studio > Dim isn't on; check nothing is soloed (Studio > Unsolo All) or muted (Studio > Unmute All).
  3. Check the track's output (right-click > Output) is Master or an output you're listening to.
  4. A deactivated track (greyed out) is silent: right-click > Activate Track.
  5. If something went extremely loud (over +12 dB, or broken audio from a plugin), the output mutes itself for 2 seconds to protect your ears and the status line says so.

I can't hear my guitar or mic while recording

  1. In Edit > Audio Settings..., the interface is the input device and its input channel is ticked.
  2. The track's input menu shows that input (not "No input").
  3. The track is armed (its R button, not the R key): its meter should move when you play. If not, check the interface's gain and cable. (An input feeds one track at a time: choosing it on another track takes it from this one.)
  4. Input monitoring (the headphones button) is Auto or On, not Off. It belongs to the input: every track on that input follows it.
  5. On a Mac, Take 5 must be allowed the microphone: System Settings > Privacy & Security > Microphone.
  6. Some interfaces have a direct-monitor knob or switch; if you hear yourself twice, set monitoring to Off.

My recording is late or out of sync with the click

Take 5 moves recordings earlier by the latency the interface reports. If takes still land late or early, measure the real round trip: a cable from an output straight to an input, Studio > Recording Latency..., Measure Delay (see "Measure recording latency so takes line up"); it's kept for each input, so measure each one you record from. Plugins that delay the sound are compensated on playback; while recording, Transport > Low-Latency Mode keeps what you hear immediate. Bluetooth headphones lag too much to record with.

I hear crackles, clicks or dropouts

  1. Raise the buffer size in Edit > Audio Settings... (for example 128 to 256, or 512 for mixing).
  2. On Windows, use the interface's ASIO driver rather than Windows Audio or DirectSound.
  3. Find the heavy ones in Window > Panels > Audio Performance (or click the CPU reading at the bottom right), then freeze or deactivate them (right-click a track > Freeze or Deactivate Track).
  4. Clicks at clip edits: turn on Edit > Snap to Zero Crossing, or add short fades.
  5. Clicks only in a mix that's very loud may be clipping: watch the master meter and the TRUE PEAK readout.

My MIDI keyboard doesn't play anything

  1. Plug it in: Take 5 finds a MIDI keyboard within a few seconds, even while it's open, and listens to every one unless it's switched off in MIDI > MIDI Inputs (ticked: listened to). If it still plays nothing, unplug it and plug it back in, or quit and reopen Take 5. A Bluetooth one has to be paired first: Bluetooth MIDI... in Edit > Audio Settings... (Mac only).
  2. Play an instrument track (Project > Add Track > Instrument...), not an audio track, and arm it (its R button).
  3. The instrument track's input should be "All MIDI Ins" or your keyboard.
  4. Check the instrument makes sound: click a key on the piano roll's keyboard, or a Drum Machine pad.
  5. A bundled instrument only plays its own range: Musical Typing dims keys out of reach.
  6. Notes stuck on? Transport > Panic, or double-click the play button.

My keyboard plays some notes twice

Some keyboards with worn contacts send a note twice. Edit > Preferences... > MIDI > Ignore Notes Sent Twice By and tick the keyboard (kept for that keyboard): a second note-on for a key still held, within 40 ms, is dropped, so a doubled note sounds and records once while fast repeated notes still work. For notes already recorded, open them in the MIDI editor and choose MIDI > Delete Doubles (notes on one key starting within 40 ms become one).

Notes or sounds are stuck on

Transport > Panic (it has no key until you give it one), or double-click the play button: every plugin is reset and all notes, sounds and the sustain pedal are released on every track and MIDI input, including plugins in their own processes. If a note keeps sticking, check the keyboard's sustain pedal and cable, and see "My MIDI keyboard doesn't play anything".

A plugin is missing from the menu

  1. Scan again: Studio > Plug-in Manager... > Scan for Plugins. If it's installed somewhere else, Options... > Scan for new or updated VST3, AudioUnit or CLAP plug-ins and choose the folders to look in. Each plugin is scanned in a separate process: one that crashes (twice) or takes more than 2 minutes is skipped, listed at the end, and tried again next time. Options... also removes plugins from the list (the selected ones, or those no longer there).
  2. Check its format:, VST3, Audio Units or CLAP; on Windows, VST3 or CLAP.
  3. Check it's installed where plugins go:, Library/Audio/Plug-Ins (in your home folder or the disk's); on Windows, C:\Program Files\Common Files\VST3 (or CLAP), or the same in %LOCALAPPDATA%\Programs\Common.
  4. Instruments are listed under Project > Add Track > Instrument... > Plugins, effects under the + slot > Plugins.

Space or Num * doesn't do anything

Space plays and stops, Num * records (on a Mac, R does too: a Mac laptop has no numpad). Single-key shortcuts don't work while you're typing in a text box (a track name, a value box): click an empty part of the tracks first. With no song open, there's nothing to play. If you changed the key set, check Edit > Key Commands... or the cheat sheet (Ctrl/Cmd/). (While On-Screen Keyboard is on, the letter keys of its keyboard play notes; Space and Num * still work.)

Send a bug report

Help > Show Log Files opens the folder with this launch's log selected ("Take 5 2026-10-31 14-05-12.log": the date and time it opened). Send it to Alan with what you did; it already has your computer, system, audio device, MIDI inputs, how the last launch ended and everything the app did. The last 20 launches' logs are kept. For a plugin problem, send "Plugin Hosts.log" from the same folder too. If Take 5 won't start, the logs are in ~/Library/Logs/Take 5 and %APPDATA%\Take 5\Logs on Windows. Edit > Preferences... > General > Detailed Log (ticked while on, and remembered) writes more, the plugins' processes too, for chasing a problem.

Windows and Mac differences

Shortcuts and menus on Windows

Where this guide says Cmd, use Ctrl; where it says Opt, use Alt (Ctrl+S saves, Ctrl+Z undoes). The shortcut that's Control on the Mac, Bounce in Place, is Ctrl+B on Windows. Return is Enter. The menu bar is inside the Take 5 window (open its menus with the mouse; Alt and F10 don't). File > Quit, Ctrl+Q, quits (on the Mac, Take 5 > Quit Take 5). Finder is Explorer, and the Trash is the Recycle Bin. In the key sets, where a Mac key and a Control key become the same Ctrl key, the second command gets Ctrl+Alt instead (Set B's MIDI Editor, Ctrl+Alt+=; Mute Notes in Sets C and F, Ctrl+Alt+M).

Keys on a Mac keyboard

A Mac laptop has no numpad, so on the Mac the numpad's transport keys have second keys: R records (as Num * does), / turns Cycle on and off (Num /), and comma and full stop go back and on a bar (Num - and Num +). The F-keys on a Mac keyboard control brightness and volume until you hold fn: press fn+F3 for the mixer, or turn on Use F1, F2, etc. keys as standard function keys in macOS's Keyboard settings. Home, End, Page Up and Page Down are fn with the arrow keys.

Where Take 5 keeps things

  • Songs: Music/Take 5 (Mac), Music\Take 5 (Windows).
  • Settings, templates and presets: ~/Library/Take 5 (Mac), %APPDATA%\Take 5 (Windows).
  • Rehearsals: Music/Take 5/Rehearsals (Music\Take 5\Rehearsals on Windows), a folder for each by date and time, with the whole recording in its Recording folder and the songs cut out of it in Takes. A rehearsal of two hours from a stereo mic takes about 2 GB, and the takes as much again: once the takes are right, the Recording folder can be deleted to save the space (the takes stay).
  • Models downloaded the first time they're used (stem separation, lyrics transcription's speech models, and the assistant's local models, in Language): the Models folder in the settings folder, ~/Library/Take 5/Models (Mac), %APPDATA%\Take 5\Models (Windows). Delete one to free the space: it's downloaded again when it's next needed.
  • The demo song: the Windows installer puts it in Music\Take 5\Take 5 Demo; on the Mac, copy it from the disk image.
  • Logs: ~/Library/Logs/Take 5 (Mac), %APPDATA%\Take 5\Logs (Windows).
  • Backups: in each song's own Backups folder, on both.

What's different on Windows

  • Audio: ASIO (with your interface's driver), Windows Audio or DirectSound, instead of Core Audio.
  • Plugins: VST3 and CLAP (Audio Units are Mac-only).
  • MIDI: no Bluetooth MIDI keyboards (pairing is Mac-only), and for MIDI between apps you need a virtual MIDI port tool (the Mac has the IAC Driver built in).
  • Printing sheet music opens the PDF in your PDF viewer to print from.
  • The Bluetooth-headset microphone switch and Rosetta for Intel-only plugins (until macOS 28, which doesn't run Intel code) are Mac-only.
  • The first launch may show SmartScreen's "Windows protected your PC": More info, Run anyway.
  • Stage mode's spoken cues are made with Windows' speech voice (on the Mac, its own voice from say).
  • The phone remote and Listen Together: the first time either is started, Windows may ask to let Take 5 use the network (allow it on private networks); the Mac may ask about incoming connections the same way.
  • About Take 5, Check for Updates... and Check for Updates at Startup are in the Help menu (on the Mac, in the Take 5 menu); on both an update installs itself and opens Take 5 again. The installer adds Take 5 to the Start menu (and, if you like, the desktop); uninstall it from Settings > Apps.
  • A new song's folder name loses dots and spaces at its end (Windows doesn't allow them).
  • Transcribe Lyrics runs on the processor on Windows; on the Mac it uses the graphics chip too, so it can be quicker there.
  • Transcribe to Tab needs macOS 13.4 or later on a Mac (Take 5 itself runs from macOS 11); on Windows it runs on any version Take 5 does.
  • The assistant's local models (Local Models...) run on the graphics card on Windows when its driver has Vulkan (else on the processor, much more slowly), on the graphics chip on a Mac with Apple silicon.

Everything else (songs, templates, song packages, parts) works the same on both. A song folder copied from one to the other opens with its audio: songs are saved the way both read (a song saved by an older version on Windows is read on the Mac too). Audio kept outside the song's folder (by a full path, such as C:\... or a network drive) isn't found on the other system: Media > Collect Audio into Project first.
