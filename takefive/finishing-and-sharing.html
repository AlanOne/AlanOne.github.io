Finishing and exporting

Export the mix as WAV, MP3 or FLAC

File > Export..., CtrlECmdE, with Export set to The mix (one file):

  • Formats: tick one or more of WAV (ticked to start with), AIFF, FLAC and MP3: a file of each.
  • Quality: 16 or 24-bit (24 to start) for WAV, AIFF and FLAC; for MP3, 128, 192, 256 or 320 kbit/s (320 to start; constant bit rate, 16-bit).
  • Sample rate: 44.1, 48, 88.2 or 96 kHz (the audio interface's rate to start with). An MP3 can't be 88.2 or 96: it's written at 44.1 or 48.
  • Range: Whole song, or Loop range (greyed until there's one: drag in the ruler). The whole song goes on past the last clip while reverbs and delays ring on, until they've died away (10 seconds at most); a loop range stops at its end.
  • Loudness: As mixed, or a target (see "Export at a loudness target for streaming").
  • MP3 tags: Title (the song's name to start with), Artist, Album and Year, for an MP3. The artist is remembered for every song; the rest goes back to how it was each time.

Export... asks where (the song's folder, "<song>.wav"); each other format gets the same name with its own extension, replacing a file of that name without asking. The export respects mute and solo, has every plugin on (even in Low-Latency Mode), is always stereo, and leaves out the click, the reference, Mono, Dim, Master Off and the listen bus. The export window shows each file as it's written with a progress bar and Cancel (which deletes the file being written). When it's done it says Export finished, with the integrated loudness, true peak and loudness range of the first file that isn't an MP3: Open in Finder (Open in Explorer on Windows) opens the folder with the file selected, Close Window closes it. MP3 works out of the box and Windows: the encoder is built in.

Export at a loudness target for streaming

In File > Export..., set the loudness to -14 LUFS (streaming), -16 LUFS (podcasts, gentler) or -23 LUFS (broadcast) instead of As mixed. The export is turned up or down to that loudness (one change of level, no limiting), but never so far that its true peak goes over -1 dBTP: a mix with loud peaks comes out quieter than the target (check the loudness the finished window shows). For a louder master, put the Limiter on the master and push its gain while watching the TRUE PEAK reading in the transport bar. With Each section, each file is brought to the target on its own. Stems keep their balance: Loudness is greyed for them.

Master the song for streaming (with the assistant)

Ask the assistant: "master this for streaming, punchy", "master it like the reference, -14 LUFS". It measures the mix (loudness, true peak, and the balance in third-octave bands, compared band by band with the reference track if you've chosen one, at matched loudness), sets up the master's EQ, compressor and Limiter from what it measured (a Dynamic EQ or Multiband Compressor for problems that come and go, a Split by mid/side for width), then measures again and adjusts: within 0.5 LU of the target (-14 LUFS unless you say another) with the true peak at or under -1 dB. It's one request, so one Undo, CtrlZCmdZ, takes it all back. Then use Master Off on the master strip (Mix > Master Off (Matched Loudness)) to hear whether the master helps.

Export stems

In File > Export..., choose Stems (one file per track, folder and bus), then a folder: a "<song> Stems" folder is made in it, with a file per top-level track, folder (everything in it) and bus, "<song> - <track>.wav" (and the other formats ticked). Stems leave out their sends (those are in the bus stems) and the master's plugins and fader, so dropped into another music app at the same start they add up to the mix before the master. Muted tracks get none; drum channels and tracks inside a VCA get stems of their own. Range applies (the whole song with its tail); Loudness and the MP3 tags don't. When it's done it says how many files.

Export each section as its own file

Add section markers first, then in File > Export... choose Each section (one file per section) (it says how many): one numbered file per section, from marker to marker ("<song> - 1 Verse.wav"; "01", "02" with ten or more), in a "<song> Sections" folder made in the folder you choose. Anything before the first marker isn't in one; the last runs to the end of the last clip. Range is greyed; a loudness target applies to each file; an MP3's title tag gets the section's name. The option is greyed out until the song has section markers (see "Add and name sections (intro, verse, chorus)").

Export just part of the song

Set a loop range by dragging in the ruler and choose Loop range in File > Export.... To save what each track plays in a marquee range as separate files, use File > Export Other Formats > Export Range as WAV... (greyed without a marquee range): a 24-bit WAV per track, through its effects or instrument and with their tails, but at an even level (no fader, pan, sends or master), named "<track> <start>-<end>.wav" by bar and beat, in the song's Exports folder to start with (one track asks for a file, several for a folder).

Make a video of the song for social media

File > Export Video... makes a video to post: the song's mix as its sound, and a picture that moves with the music. In the window:

  • Part of the song: the whole song, the loop (if one's set), or a section by its marker (a chorus is often enough for a reel; most sites take up to a minute or 90 seconds).
  • Shape: 9:16 tall for stories, reels and shorts (1080 x 1920), 1:1 square for a feed (1080 x 1080) or 16:9 wide for YouTube (1920 x 1080); 30 frames a second, or 60 for smoother movement (a bigger file).
  • Moving with the music: Bars (the spectrum, lows at the left), a Waveform, or a Ring.
  • Colours: the background and the bars' colour; Picture... puts a photo behind it all (the band, the cover art), filling the shape and dimmed so the rest reads; No Picture takes it away.
  • Song and Band: the names at the top (the band's starts as your name from File > Share with Bandmates).
  • The lyrics, word by word: the lyrics lane's line being sung, its words lighting up as they go, the next line under it (see "Write lyrics along the song").

The preview shows a frame; drag the slider under it to look through. Export... asks where to save the MP4 (the song's Exports folder to start with) and renders it, with progress and Stop: about as long as the part takes to play, or less. Then it's shown in Finder (Explorer on Windows), ready to send to your phone. The sound is the mix as File > Export makes it (H.264 video, AAC sound, which every phone and site plays).

Write music to a video (video in the song)

File > Import Video... puts a video (MP4 or MOV: a band's live video, a short film, an advert) in the song, its first frame at the playhead, and opens the video window (View > Video, also in View > Panels). The window shows the frame at the playhead as the song plays, or as you move the playhead, with the video's timecode (hours:minutes:seconds:frames) under it; before or after the video it says so. The video's sound arrives on a track of its own ("<video> Sound"), lined up with the picture: a guide to play to, or the camera's sound to mix with the band's recordings. A song has one video: importing another replaces it (the first one's sound track stays). The video is kept with the song by where the file is (keep it inside the song's folder, so it goes wherever the song goes).

Line the video up with the song

In the video window (View > Video), Start at Playhead moves the video so its first frame is at the playhead, its sound's clips moving with it: put the playhead on the bar the picture should start at. To start the song partway into the video, import it with the playhead at the song's start and then move the song's music later, or drag the sound's clip and press Start at Playhead with the playhead where the clip now starts. Remove takes the video out of the song (its sound's track stays, to delete or keep). Each of these is one undo step.

Put markers at the video's cuts

In the video window, Markers at Cuts finds where the video cuts from one shot to another and puts a section marker at each ("Shot 2", "Shot 3"...), so you can write the music to the edit: the sections lane shows them, and Track > Arranger Chains and the chord chart read them like any other markers. Soft fades and dissolves aren't cuts and get no marker.

Set the song's timecode (start at 01:00:00:00)

Picture editors usually start a film or an advert at 01:00:00:00. To count the song the same way, press Timecode... in the video window, type where the song's start is (hours:minutes:seconds:frames, like 01:00:00:00; for drop-frame rates, 00:59:59;29 also works) and choose the frame rate (23.976, 24, 25, 29.97, 29.97 drop-frame, 30, 50, 59.94, 59.94 drop-frame or 60 frames a second). The video window then shows the song's timecode on the left under the picture, beside the video's own, and an AAF exported from the song starts there. Clear counts from 00:00:00:00 again. Setting it is one undo step. An AAF imported from a session that started at a timecode sets it for you.

To see it in the tracks, choose View > Lanes > Timecode in Ruler: the song's timecode runs along the top of the ruler, above the bar numbers, closer together as you zoom in. Without a timecode set, it counts from 00:00:00:00 at the video's frame rate (25 without a video).

Export the video with your mix

In the video window, Export with the Mix... saves the video again ("<video> (new mix).mp4" beside it to start with) with the song's mix over the video's length as its sound, in place of what it had; the picture is unchanged. The mix is made first (as File > Export makes it), then the video, with progress along the bottom of the frame; click the button again to stop. Mute the video's own sound track first if it shouldn't be in the mix. Then the file is shown in Finder (Explorer on Windows).

Put songs together as an album or EP

File > Album... opens a window (choose it again to close it: an album not saved is gone): the album's Title, Artist and Year, and its songs. Add Songs... adds songs (their .tracktionedit files) at the end; Move Up, Move Down and Remove put them in order (each song's title is its file's name). For the selected song, Then: a gap of some seconds (2 to start) before the next, or crossfade over some seconds into it (an even crossfade; the last song has neither); Trim (dB), -24 to +12, turns it up or down by hand after matching. Match to sets the loudness every song is brought to: -14 LUFS (streaming) (to start with), -16 LUFS (podcasts, gentler), -11 LUFS (loud), -9 LUFS (very loud) or Off: as they're mixed. Whatever the choice, no song goes over -1 dB true peak: one that would is left a little quieter, and says so. Measure shows each song's loudness now. Render Album... asks for a folder and writes 24-bit, 44.1 kHz files there, replacing ones of the same name:

  • a WAV per song ("01 Hearts Explode.wav"...), matched, with its reverb's tail (up to 4 seconds, until it's silent), and its title, artist, album, year and track number in it;
  • one WAV of them all ("<album>.wav"), in order with the gaps and crossfades, with a marker where each song starts;
  • a cue sheet ("<album>.cue") beside it, to burn a CD or for a distributor.

Then a box lists each song's loudness and true peak and the whole album's length. Each song is rendered from its file, through its own master, so a change to a mix is in the next render (the open song is saved first if it's one of them). Save... keeps the album as a .t5album file (it offers the folder your songs are in); Open... brings it back. The album remembers where each song is: a song moved since shows red, "(missing)", and has to be added again.

Hand a song to another music app (DAWproject)

File > Export Other Formats > Export DAWproject... saves the song as a .dawproject file, the open format many music apps read: the tracks and folders (as submixes), buses (as effect channels), MIDI clips and their notes, audio clips (the audio files go inside it) with their fades, each channel's fader, pan, mute, solo and sends, the automation of faders, pans and sends, the section markers, and the tempo (its changes as tempo automation; only the starting time signature). It goes in the song's Exports folder to start with. Installed VST3 plugins go across with their settings (a few older ones by name only); CLAP and AU plugins by name (load their settings again there); a bypassed plugin stays bypassed. The built-in EQ and Compressor become the other app's own; Take 5's other effects and instruments (the amp, the delay...) can't go across, and are listed in each track's comment. Every folder goes as a submix (a VCA too). Not carried: the master's plugins (its fader and pan are), clip gain, and looped audio clips; stretched or reversed clips go as recorded. Afterwards Take 5 says what didn't go across ("Exported, mostly"). For an app that reads AAF but not DAWproject (and video editors), export an AAF instead.

Export an AAF session

File > Export Other Formats > Export AAF... writes the song as an AAF session: audio tracks with their clips, fades and crossfades, clip gain, volume, pan and the markers. It asks first where the audio goes: In the AAF or WAV Files Beside It (a "<name> Audio" folder, a mono WAV per channel), then where to save (the song's Exports folder to start with). Clips an AAF can't describe (stretched, warped, reversed, looped, pitch-shifted, with envelopes or clip effects) go out rendered as they sound. MIDI, muted tracks and clips, plugins, sends and automation don't go, and the export says so, with how many tracks and clips went, and any track split in two (mono and stereo clips, or overlapping ones). It starts at 00:00:00:00 at 25 frames a second. A song imported from an AAF that started at a timecode starts there again. For MIDI parts, use File > Export Other Formats > Export MIDI File....

Sharing with bandmates

Let a bandmate listen and comment from home (Listen Together)

Transport > Listen Together..., Start Listening Together: the window shows an address with a code (http://192.168.1.20:8790/?code=k7m2xq, say). Send it to your bandmate; they open it in a browser and press Listen, and hear what Take 5 plays (the mix, as you hear it) a second or two behind. Under it they can type their name and a comment ("snare's too loud here") and Send at this moment: it lands in the song as a comment with their name, at the place they were hearing (on the sections lane; hover over its dot to read it), and the status line says so. The window shows how many are listening. Stop Listening Together ends it; it keeps running with the window closed. Only someone with the code can listen (a new one each time Take 5 opens); after five wrong codes from one place, it isn't answered from there for a minute, so the code can't be guessed. Up to eight can listen at once.

On the same network (a bandmate in the next room, a phone) it works as it is. For someone elsewhere, your router has to pass the port the window shows (8790, say) on to this computer ("port forwarding" in the router's settings), and they use your internet address instead of the one shown. The delay makes it right for hearing a mix, not for playing along.

Put my name on parts and comments

Settings > Your Name...: the name on the parts you send and the comments you write ("Alan: retake this bar"). It starts as your computer account's first name. Set it once on each computer (it's for every song), before you send parts or leave comments, so bandmates can see who played what. A changed version of a track you have arrives as an alternative named after them. Changing it later doesn't change earlier comments or parts.

Send a song to a bandmate (song package)

File > Share with Bandmates > Save Song Package... makes one .take5song file (on the Desktop to start with) with the song as it is now (unsaved changes too) and only the files it uses: the audio of its clips and takes, sampler and drum kit samples, and the Capture Player's captures and cabinets (a TONE3000 tone goes as a link, downloaded again at the other end). Not the backups, snapshots or exports. Up to 4 GB of audio: for more, send parts a few tracks at a time. Send it any way you like. Double-clicking it (or File > Open Song...) closes the song you have open (asking to save) and opens it as a song of its own in Music/Take 5 ("<song> (2)" if the name is taken), with its takes, drum kits and plugin settings. Its third-party plugins have to be installed on that computer too.

Work on a song through a shared band folder

  1. On your computer: File > Share with Bandmates > Share in Band Folder... and choose a folder your band shares (one a cloud or sync service keeps the same on everyone's computer). A folder named after the song appears there with the package ("<song> - from <you> <date>.take5song") and a Parts folder. Take 5 remembers the band folder for this song on this computer.
  2. A bandmate double-clicks the package there: it opens as their own copy, knowing the band folder (if they opened a copy from elsewhere, they choose it with Share in Band Folder...).
  3. They record a part, then Share with Bandmates > Send Parts...: every track is listed, the new ones (not in the song when it was shared, sent or received) ticked and marked "(new)"; Send to Band Folder (or Save as a File... to send it another way). Inputs aren't sent.
  4. Take 5 checks the folder every 20 seconds or so (not while recording or while a window is asking something). When parts arrive, "<name> sent <tracks> for <song>" asks to import them, the oldest first: Import, Later (asked again next time the song opens) or Don't Import.

Nobody's song file is ever overwritten: only .take5song and .take5parts files go in the shared folder, and sharing again adds another package.

Import parts a bandmate sent

Double-click a .take5parts file, or File > Share with Bandmates > Import Parts.... New tracks land as new tracks, where they were played (on the same bars even if the tempo changed); a new version of a track you already have arrives as an alternative of it, named after who played it, playing, its takes there to comp (right-click the track > Alternatives); a track that hasn't changed is left as it is. New tracks go in the folder they were in, if you have it. Their audio is copied into the song's Audio folder, and their comments added. A box says what came in; CtrlZCmdZ takes it all out again. Parts for another song are refused (open the song they're for first).

Leave a comment at a point in the song

Right-click the sections lane > Add Comment Here... and type it: a dot with your initial, signed with your name, at that point (on the grid; it stays on its beat if the tempo changes). Hover over the dot to read it (who, what, where); right-click it > Remove Comment. Both are undo steps. Comments go to bandmates with the parts you send and in a song package, and removing one removes it for them too.
